
# Employee Attrition Analytics – Power BI Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyze employee attrition and understand the key factors influencing employees to leave an organization.

## Key Analysis
- Department-wise employee attrition
- Age group-wise attrition analysis
- Gender-wise employee attrition
- Average salary analysis
- Key factors contributing to employee turnover

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analytics
- Excel
- power Query

## Dashboard Overview
The project includes a single-page interactive dashboard that provides insights into employee attrition patterns across different departments, age groups, genders, and salary levels.

## Project Objective
To help HR teams identify employee attrition trends, understand workforce patterns, and make data-driven decisions to improve employee retention.
